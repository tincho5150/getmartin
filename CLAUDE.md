# getmartin.com
Static site deployed on Vercel. Push with: git add . && git commit -m "msg" && git push origin main
## Files
- learn.html — Learn page (main work in progress)
- index.html — Homepage
- css/global.css — Design system, single source of truth
- learn/ — 10 article pages
- proof/ — 3 case study pages
## Design system
Navy #1e2c3a, lime #b8d400, white #f0eff0
Never add inline styles that duplicate global.css rules
